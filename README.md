# AI Object Detection System

## Overview

The AI Object Detection System is a Python application
that uses YOLOv8 to identify and locate objects in images.

Users can upload an image through a Streamlit interface
and view the detected objects with bounding boxes.

## Technologies Used

- Python
- Ultralytics YOLOv8
- Streamlit
- Pillow
- Git
- GitHub

## Features

- Image upload
- AI-powered object detection
- Annotated image display
- Object labels and confidence scores
- Interactive graphical user interface

## Installation

1. Clone the repository.
2. Create a Python virtual environment.
3. Install the required dependencies.
4. Run the application.

## Run Locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
